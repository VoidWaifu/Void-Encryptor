# Void Encryptor 🔐

**Безопасное шифрование файлов прямо в браузере.**

[Открыть приложение](https://voidwaifu.github.io/Void-Encryptor/)

## Что это?

Void Encryptor — инструмент для шифрования текста и файлов (изображения, аудио, видео) с использованием **AES-256-GCM**. Всё работает локально в браузере — данные никуда не отправляются.

## Возможности

- 📝 **Шифрование текста** и любых файлов
- 🖼️ **Поддержка изображений, аудио, видео** и других форматов
- 🔑 **Генератор надёжных паролей** с настройками
- 📊 **Индикатор сложности пароля** с энтропией
- 🌍 **Два языка** — русский и английский
- 📦 **Формат .void** — собственный формат зашифрованных файлов
- 👁️ **Предпросмотр расшифрованных файлов** — изображения, аудио, видео

## Безопасность

- 🔒 **AES-256-GCM** — военный стандарт шифрования
- 🔐 **PBKDF2** — 100 000 итераций для защиты от перебора
- 🎲 **Web Crypto API** — криптографически безопасный генератор
- 🖥️ **100% локально** — данные не покидают браузер

## Как использовать?

### Шифрование
1. Введите текст или добавьте файлы
2. Создайте или введите пароль
3. Укажите имя файла
4. Нажмите «Зашифровать» и скачайте .void файл

### Расшифровка
1. Загрузите .void файл
2. Введите пароль
3. Нажмите «Расшифровать»

## Технологии

- **Чистый HTML + CSS + JavaScript**
- **Web Crypto API** — встроенная криптография браузера
- **Без серверов** — работает офлайн

## ⚠️ Важно

**Запомните пароль!** Без него невозможно расшифровать .void файлы.
